# rhode mini bag — Proyecto Daniela Mira

Proyecto Integrador de Contenidos y Creatividad III
## La idea

Un mini juego arcade tipo "catcher" para la marca de belleza **rhode** (Hailey Bieber). El jugador mueve una canasta con el joystick y tiene que atrapar los productos correctos de rhode mientras esquiva distractores, para sumar puntos y superar su récord.

La estética combina dos mundos: la identidad limpia y minimalista de rhode (crema, blush, rosa) con una estética pixel/arcade retro para toda la interfaz de juego, como si fuera un cabinet de arcade vertical.

## Estado del proyecto

Por ahora están armadas las pantallas de **Home** y **Cómo Jugar**, con navegación entre ellas y componentes con estado (por ejemplo el efecto de botón presionado). El resto de las pantallas (selección de avatar, niveles jugables, ranking) va a ir sumándose en las próximas entregas.

## Cómo correrlo

```
npm install
npm run dev
```
